# Research Direction Brainstormer

paper-finder의 마지막 단계. 랭킹된 논문들을 입력으로 받아 **연구 방향성**을 제안한다.

## 역할

이 스킬은 **브릿지(handoff) 역할**만 한다. 실제 ideation은 글로벌 시스템 스킬 `brainstorming-research-ideas` (+ 보조로 `creative-thinking-for-research`)가 수행한다.

## 절차

### 1. 컨텍스트 준비
`.paper-finder/ranked.json` (또는 report.md) 에서 다음을 추출:
- top 10~15 논문의 제목 + venue + tldr/abstract
- 빈도 높은 키워드/메서드 (TF-IDF 단순 카운트)
- 시간 분포 (연도별 논문 수)
- venue 분포

### 2. brainstorming-research-ideas 스킬 invoke
다음 메시지를 구성해 Skill 도구로 호출:

```
이 분야의 최근 논문 N편을 분석했다:

[Top papers]
1. <title> — <venue year> — <tldr>
...

[Observed patterns]
- 주요 메서드 흐름: <...>
- 자주 등장하는 데이터셋: <...>
- 시간 분포: <2022: X, 2023: Y, ...>
- venue 분포: <...>

이 패턴을 기반으로 다음을 제안해줘:
1. 현재 연구의 명확한 gap 3개
2. 그 gap을 메우는 연구 방향 5개 (조합/유추/제약 변형 등 활용)
3. 각 방향의 실현 가능성 평가 (데이터/계산 요구량 + 차별성)
```

### 3. 결과를 별도 directions.md로 먼저 작성
`<out>/directions.md`에 다음 형식으로 저장 (재사용·디버깅 용이):

```markdown
## Suggested Research Directions

> Generated by brainstorming-research-ideas based on the N papers above.

### Gap 1: <name>
- **관찰:** ...
- **방향:** ...
- **실현가능성:** ...

(반복)
```

### 4. paper-report-builder의 `--append-directions`로 레포트 통합
```bash
python "$PLUGIN_DIR/scripts/build_report.py" \
  --out-md "papers/<slug>/report.md" \
  --out-docx "papers/<slug>/report.docx" \
  --append-directions "papers/<slug>/directions.md"
```

- 이미 `## Suggested Research Directions` 섹션이 있으면 idempotent하게 skip
- docx도 동일하게 naive md → docx 렌더링으로 같은 내용 append
- `--input` 없이 단독 호출 가능 (Phase 4 따로, Phase 5 따로)

## brainstorming-research-ideas 호출 형태

```
Skill: brainstorming-research-ideas
args: "다음 N편 논문 기반 gap 분석 + 5개 방향 제안 + 실현가능성 평가"
```

스킬이 사용 가능하지 않은 환경(시스템 스킬 로드 실패)이면 `creative-thinking-for-research`로 fallback. 둘 다 없으면 Task 도구로 `oh-my-claudecode:architect` 에이전트에게 동일 프롬프트로 위임.

## 안전장치

- 입력 논문이 5편 미만이면 "데이터 부족" 안내하고 brainstorming 단계 skip.
- 모든 제안은 반드시 **이번 검색 결과에 근거**해야 한다 (논문 번호로 인용). 일반론적 제안 금지.
- 사용자의 기존 연구 컨텍스트(notion-rag로 본인 노트 검색 가능)와 충돌하면 그 차이를 명시.
